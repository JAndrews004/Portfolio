# 02_Gameplay_Mechanics

This folder contains projects demonstrating **basic gameplay mechanics** in Unity and Unreal Engine. Both projects build on the movement systems from `01_Basics` and showcase interactive elements and health systems.

---

## 🕹️ Unity: Health & Interaction System

### 🧠 Overview

A Unity project demonstrating a simple health system with player interaction:

- Lava floor damages the player on contact
- Health orb pickups require input to collect and restore health
- Health bar displays player health
- Door interaction: opens and closes with input

### 🚀 Features

- Health system with UI bar
- Lava damage mechanic
- Health pickups requiring input
- Door interaction (open/close)
- Player movement from `01_Basics`

### 🎮 Controls

| Action              | Key |
|--------------------|-----|
| Move                | WASD / Arrow Keys |
| Jump                | Space |
| Sprint              | Left Shift |
| Crouch              | Ctrl |
| Interact / Pick Up  | E |
