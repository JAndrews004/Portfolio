# 01_Basics

This folder contains two foundational game development projects — one in **Unity** and two in **Unreal Engine** — demonstrating basic character movement mechanics. These projects are designed to showcase core movement systems and input handling early in my portfolio.

---

## 🕹️ Project 1 — Unity: Basic Character Movement

### 🧠 Overview

A Unity project demonstrating a basic 3D character controller using physics (`Rigidbody`). This controller supports:
- **Walk / Run (Sprint)**
- **Jump**
- **Crouch**
- **Slide**

Movement is physics based and uses `Rigidbody` forces for movement and interaction.

### 🚀 Features

✔ Rigidbody-based movement  
✔ Sprint modifier  
✔ Jumping with gravity  
✔ Crouch + slide mechanic

### 🎮 How to Play

1. Download the Unity build below.
2. Open the `.exe` file (Windows) or run the appropriate build for your platform.
3. Use the controls below to move the character.

### 🎮 Controls

| Action      | Key |
|-------------|-----|
| Move        | WASD / Arrow Keys |
| Jump        | Space |
| Sprint      | Left Shift |
| Crouch      | Ctrl |
| Slide       | Crouch + Forward |
